## 1. Multi-modal Large Language Model

---

지금까지 배운 LLM은 text를 입력으로 받고, text를 출력하는 딥러닝 모델입니다. 하지만 다음과 같이 현실의 다양한 문제는 text 뿐만 아니라 다른 형태의 입력도 받아야 해결할 수 있습니다:

- **게임:** 컴퓨터나 비디오 게임들은 text 정보 뿐만 아니라 이미지로 현재 상황을 표현합니다. 게임을 하는 AI를 만들려고 한다면 이미지, text 등을 입력받을 수 있어야 합니다.
- **악보 변환:** 노래를 듣고 악보로 변환하는 것은 오디오를 입력으로 받습니다. 이러한 문제들은 오디오를 입력으로 받을 수 있어야 합니다.

그래서 많은 연구자들이 기존의 LLM이 text 이외에 이미지나 오디오 같은 정보도 받을 수 있도록 발전시켜왔습니다. 이러한 형태의 LLM은 여러 가지 형태(modal)의 입력을 받는다고 해서 MLLM이라고 부릅니다.

## 2. Vision-language Model (VLM)

---

<aside>
💡 **이미지, 오디오 등 다양한 입력을 받는 MLLM이 있습니다. 이번 챕터에서는 그 중에서도 이미지를 같이 입력 받아 처리할 수 있는 VLM에 대해 소개합니다.**

</aside>

### 2.1 Vision Transformer

이번 챕터에서는 VLM을 다루기 전에 구성 요소 중 하나인 vision transformer(ViT)를 소개합니다.

Transformer는 token sequence를 입력으로 받는 모델입니다. 여기서 특정 이미지를 token sequence로 바꿔서 Transformer 입력으로 주는 모델을 ViT라고 부릅니다:

![스크린샷 2024-10-11 오후 2.19.42.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/83c75a39-3aba-4ba4-a792-7aefe4b07895/1b9c2f80-63b8-4fdd-817a-7fdc324f5064/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_2024-10-11_%EC%98%A4%ED%9B%84_2.19.42.png)

위에서 Transformer Encoder는 text 처리할 때 사용하던 Transformer와 같은 모델을 사용하고, 차이는 이미지를 token sequence로 변환하는 과정에서 생깁니다.

Token sequence로의 변환에서 이미지가 text와 다른 점은 다음과 같습니다:

- **Patch 단위 분리:** 먼저 이미지를 특정 patch size로 분리합니다. 위의 그림에서 왼쪽 아래를 봐주시면 됩니다. 일정한 patch size로 이미지를 쪼갭니다.
- **같이 학습되는 positional embedding:** 이미지는 text와 달리 2차원이기 때문에 positional encoding을 정의하는 것이 힘듭니다. 그래서 patch들을 1차원으로 sequence로 나열하되, positional encoding은 각 index마다 별개로 학습을 합니다.

ViT가 다른 비전 특화된 모델과 비교해서 얻는 이점은 다음과 같습니다:

- **Data가 많을 때 높은 성능을 발휘:** ViT는 Transformer이기 때문에 inductive bias가 없습니다. 그래서 data가 적으면 inductive bias를 가지고 있는 비전 특화 모델들이 잘하지만, data가 충분히 많으면 더 좋은 성능을 보입니다.
- **Text Transformer와 연동이 쉬움:** ViT는 Transformer이기 때문에 출력도 token sequence입니다. 그래서 text를 입력으로 받는 Transformer와 연계하기 쉽다는 장점이 있습니다.

### 2.2 Vision Transformer with LLM

이번 챕터에서는 이제 ViT와 LLM을 결합하여 어떻게 VLM을 만드는지 소개합니다. VLM은 다음과 같은 구조를 가지고 있습니다:

![스크린샷 2024-10-11 오후 2.25.44.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/83c75a39-3aba-4ba4-a792-7aefe4b07895/9f719b3e-5c5f-43f3-be5e-987b2d01d028/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_2024-10-11_%EC%98%A4%ED%9B%84_2.25.44.png)

- **Vision encoder:** 이전 챕터에서 소개한 ViT를 vision encoder로 두어, 이미지로부터 token sequence를 뽑아냅니다.
- **Projection layer:** projection layer를 두어 token sequence에 적용합니다. Projection layer는 token마다 동일한 MLP를 적용하는 것이 예시 중 하나입니다.
- **Language model:** 이미지가 vision encoder와 projection layer를 거쳐 만들어진 token sequence를 text와 concat하여 language model에 그대로 넣어줍니다.

즉, ViT의 출력이 text와 같은 token들의 sequence임을 이용하여 단순히 ViT의 출력을 입력 text와 concat하는 식으로 구현됩니다. 이러한 VLM은 이미지, text로 구성된 corpus로 fine-tuning합니다. 이미지와 text 쌍들의 모임이 corpus가 됩니다.

이렇게 만들어진 VLM을 가지고 다음과 같은 task들을 수행할 수 있습니다:

- **이미지 질의응답:** 이미지와 이미지와 관련된 질문을 해결할 수 있습니다. 예를 들어 MNIST의 사진을 주어주고, text 입력으로 “주어진 손글씨 사진에 어떤 숫자를 그려져 있어?”와 같은 질문에 대응할 수 있습니다.

    ![스크린샷 2024-10-11 오후 2.31.15.png](https://prod-files-secure.s3.us-west-2.amazonaws.com/83c75a39-3aba-4ba4-a792-7aefe4b07895/58776f40-f53a-46ee-b2b7-03b4022878ce/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_2024-10-11_%EC%98%A4%ED%9B%84_2.31.15.png)

- **도표 이해:** 히스토그램이나 차트 같은 것을 입력으로 주어, 통계를 뽑아낼 수 있는 task를 수행할 수 있습니다.

### 2.3 GPT API with Image Input

실습을 시작하기에 앞서, 이전 GPT API 실습과 똑같이 다음 부분들을 미리 구현해둡시다:

- OPENAI_API_KEY 설정
- `openai` library를 불러오고 `client` 준비.

먼저 웹 URL로 접근할 수 있는 이미지를 어떻게 GPT에게 입력으로 줄 수 있는지 살펴봅니다.

예를 들어 [이 링크](https://upload.wikimedia.org/wikipedia/commons/thumb/d/dd/Gfp-wisconsin-madison-the-nature-boardwalk.jpg/2560px-Gfp-wisconsin-madison-the-nature-boardwalk.jpg)의 이미지는 URL이 존재합니다. 이 URL은 아래 코드에서 `<image_url>`의 부분으로 넣으면 GPT에게 “What’s in this image?”라는 text와 함께 입력으로 주게 됩니다:

```python
response = client.chat.completions.create(
  model="gpt-4o-mini",
  messages=[
    {
      "role": "user",
      "content": [
        {"type": "text", "text": "What’s in this image?"},
        {
          "type": "image_url",
          "image_url": {
            "url": <image_url>,
          },
        },
      ],
    }
  ],
  max_tokens=300,
)

print(response.choices[0])
```

API 사용법은 기존과 같습니다.

이번에는 내 컴퓨터에 저장된 이미지를 입력으로 주는 방법을 다룹니다. 먼저 다음 함수를 구현합시다:

```python
def encode_image(image_path):
  with open(image_path, "rb") as image_file:
    return base64.b64encode(image_file.read()).decode('utf-8')
```

디스크의 이미지를 base64 encoding으로 불러오는 함수입니다.

구체적인 내용은 모르셔도 무방합니다. 이제는 다음과 같이 GPT API에 넘겨줄 구성요소들을 준비합니다:

```python
image_path = "path_to_your_image.jpg"
base64_image = encode_image(image_path)
```

`image_path`에 저장된 이미지는 `base64_image`라는 이름의 변수에 저장됩니다.

다음은 GPT api로 넘겨주는 코드입니다:

```python
response = client.chat.completions.create(
    model="gpt-4o-mini",
    messages=[
        {
            "role": "user",
            "content": [
                {
                    "type": "text",
                    "text": "What is in this image?",
                },
                {
                    "type": "image_url",
                    "image_url": {"url": f"data:image/jpeg;base64,{base64_image}"},
                },
            ],
        }
    ],
)

print(response.choices[0])
```

`response.choices[0]`를 보면 response가 저장되어 있는 것을 알 수 있습니다.
